◆ SBIR / STTR · TECHNICAL PROPOSAL

Unified Dual-Modulus PQC Accelerator

A single reconfigurable FPGA datapath that performs both NIST post-quantum key encapsulation (ML-KEM) and digital signatures (ML-DSA) — parametric across all three security levels, with a hardware-native Ethernet host interface.

FIPS 203 · ML-KEM FIPS 204 · ML-DSA FIPS 202 · Keccak/SHAKE Arty A7-100T AXI4-Stream over Ethernet

01 The Problem

Cryptographically-relevant quantum computers will break the RSA and elliptic-curve algorithms that protect today's industrial, medical, and defense communications. Adversaries are already harvesting encrypted traffic to decrypt later. NIST has standardized the replacements — but software implementations are too slow and too exposed for constrained, high-assurance embedded systems.

02 The Innovation

Most designs implement ML-KEM and ML-DSA as separate blocks, wasting fabric. K-Fam's core unifies them on a single dual-modulus arithmetic datapath with a shared Keccak engine — selectable at compile time across NIST levels 1, 3, and 5. The result is a smaller, cheaper, certifiable block that drops into existing designs.

03 Technical Maturity

This is not a concept. A working prototype runs on the Arty A7-100T with timing closed at 100 MHz, validated against NIST's ACVP test vectors, with documented constant-cycle side-channel hardening. The underlying research is peer-reviewed and published.

04 Commercial Dual-Use

The same core secures defense tactical radios, FDA-regulated medical telemetry, industrial wireless control, and critical infrastructure — any system facing a multi-decade service life and a federal post-quantum migration mandate.

◆ Proposed Development Roadmap

PHASE I

Feasibility & Hardening

Harden the parametric core, complete full FIPS 203/204 conformance across all NIST levels, and demonstrate the standalone FPGA compliance boundary with a host-over-Ethernet reference design.

PHASE II

Productization & Integration

Port to production-grade FPGA/SoC targets, add formal side-channel evaluation, and package the core as a licensable, integration-ready IP block with a documented verification bundle.

PHASE III

Commercialization

Transition the validated core into defense, medical, and industrial platforms through IP licensing and integration support — K-Fam's Tier 03 engagement model.
